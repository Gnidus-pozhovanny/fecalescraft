# FecalesCraft by Gnidus

Сборка Minecraft на основе Create Aeronautics.

## Установка

1. Скачайте `FecalesCraft.mrpack` из [последнего релиза](https://github.com/Gnidus-pozhovanny/fecalescraft/releases/latest).
2. Импортируйте файл в лаунчер с поддержкой формата Modrinth.
3. Запустите созданный профиль.
